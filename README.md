# Campus Event Guide

## Project Description
This project is a campus event website for students at Piedmont State University. The site is meant to help students find upcoming events and get more information about a featured event.

## Layout Decisions
I used Flexbox for the navigation, hero section, and related events section. Flexbox made it easier to line things up and let the items wrap when the screen gets smaller.

I used CSS Grid for the upcoming events section on the home page. The first event is wider than the other cards. I also used Grid on the event page for the main event information and the sidebar.

## Responsive Design
I used two media queries.

At 800px, the hero section stacks vertically, the event cards change to one column, and the sidebar moves below the main event information.

At 500px, the navigation becomes vertical and the related event cards stack.

I tested the layout by resizing the browser window.

## Semantic HTML
I used semantic elements like `header`, `nav`, `main`, `section`, `article`, `aside`, `figure`, `time`, and `footer`.

I used these so the page structure is easier to understand and the HTML matches the type of content inside each section.
